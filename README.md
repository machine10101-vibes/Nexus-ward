# Nexus Ward

A 3D space tower defense game. Hold planetary cores on Mycelion, Kron Forge, and Aegis Rift against organic, mechanical, and hybrid incursions.

## Play

Open the live deployment and drop in. No account required. Progress is saved in the browser.

## How to hold

1. Choose a battery, then tap a hex platform beside the path.
2. Press **Deploy** when the line is ready. Starting the next wave quickly pays an early-deploy bonus.
3. Air units ignore Pulse and Frost. Lance, Tesla, and Rail cover the sky.
4. Same-type batteries placed close together **link** for extra damage. Rank 3 unlocks an overdrive.
5. **Surge (Q)** marks every hostile. **Overclock (E)** haste-fires the grid.

| Key | Action |
| --- | --- |
| 1–5 | Batteries |
| Space | Start wave |
| Q / E | Surge / Overclock |
| F | Speed |
| A | Auto-incursion |
| U | Upgrade |
| X | Salvage |
| Esc | Pause |

## Worlds

- **Mycelion** — living planet. Ground packs first; bring a lance before spores take the air.
- **Kron Forge** — mechanical foundry. Thick armor. Rails and Tesla cut steel.
- **Aegis Rift** — hybrid scar. Mix slow control with air cover.

## Stack

React, TanStack Start, Three.js (`@react-three/fiber`), Tailwind v4.

```bash
npm install
npm run dev
```
